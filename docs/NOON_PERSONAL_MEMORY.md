# Mémoire personnelle d’organisation

Les préférences sont stockées uniquement dans `planning-preferences.json`, exclu de Git et créé avec des droits locaux restreints.

Chaque préférence contient un texte explicite, une source, une date, une confiance et un verrou. L’écran Réglages permet de consulter, verrouiller, déverrouiller ou supprimer chaque règle et de désactiver entièrement l’apprentissage.

Noon n’enregistre pas de profil psychologique. Les corrections portent uniquement sur l’organisation observable : durée, priorité, créneau, report et type de travail. Une préférence verrouillée n’est jamais remplacée automatiquement.
