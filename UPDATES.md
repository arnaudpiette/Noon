# Mises à jour

Les mises à jour sont volontairement désactivées : aucune source HTTPS signée n’est encore configurée. Noon ne télécharge ni n’installe automatiquement une version.

Le futur flux devra vérifier au maximum une fois par jour, afficher version et changelog, demander l’accord avant installation et refuser tout artefact non signé dans une application signée. Aucune release n’est publiée par cette configuration.
