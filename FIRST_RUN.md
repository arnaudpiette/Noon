# Premier lancement

Noon n’active jamais automatiquement le microphone. Au premier lancement, vérifiez progressivement : confidentialité, langue, microphone, sortie audio, raccourcis, lancement à l’ouverture de session, dossiers Focus, budget, connecteurs, Rappels et notifications.

Chaque permission peut être reportée. Le raccourci par défaut est `Control+Option+N`; Conversation Live utilise `Control+Option+Shift+N`. Le lancement à l’ouverture de session est désactivé par défaut.
